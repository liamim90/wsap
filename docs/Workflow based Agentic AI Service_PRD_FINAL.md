# **절차 기반 Agentic AI 서비스 PRD (Product Requirements Document)**

*   **문서 버전:** v2.0 (MVP & Phased Roadmap)
*   **최종 수정일:** 2024년 5월 21일
*   **문서 목적:** '절차 기반 Agentic AI 서비스'의 제품 요구사항, 기술 명세, 개발 로드맵을 정의하여 팀 전체의 목표를 통일하고 성공적인 제품 개발을 위한 가이드를 제공함.

---

### **1. 제품 개요 (Overview)**

본 문서는 특정 업무 수행 절차(SOP)를 AI Agent의 작업 계획(Planning) 단계에 주입하여, 예측 가능하고 안정적인 결과물을 도출하는 **"절차 기반 Agentic AI 서비스"** 개발을 위한 제품 요구사항 명세서(PRD)입니다.

본 서비스의 핵심은 **'워크플로우 생태계'** 구축에 있습니다. 사용자는 공식 템플릿, 맞춤형 컨설팅 템플릿, 그리고 자신이 직접 만든 커스텀 템플릿을 활용하여 반복적인 업무를 자동화할 수 있습니다. 에이전트는 사용자의 요청에 따라 **'절차 기반 모드'** 또는 **'자율 모드'**로 동작하며, 정형화된 업무와 비정형화된 업무를 모두 처리할 수 있는 유연성을 제공합니다.

---

### **2. 목표 (Goals)**

*   **신뢰성 및 유연성:** 사전 정의된 업무는 '절차 기반 모드'로 완벽하게 수행하고, 정의되지 않은 업무는 '자율 모드'로 유연하게 대처하여 신뢰성과 범용성을 동시에 확보합니다.
*   **협업 및 확장성:** 개인, 팀, 조직 단위의 데이터 접근 및 공유를 지원하여 협업 효율성을 높이고, 복잡한 비즈니스 워크플로우를 자동화할 수 있는 확장 가능한 플랫폼을 구축합니다.
*   **사용자 경험 혁신:** 복잡한 업무를 간단한 채팅으로 지시하고, Agent가 자율적으로 처리하는 과정을 투명하게 관찰할 수 있는 직관적인 사용자 경험을 제공합니다.

---

### **3. 사용자 페르소나 (User Persona)**

*   **비즈니스 분석가/기획자:** 반복적인 데이터 분석, 시장 조사, 보고서 초안 작성 등의 업무를 자동화하여 핵심적인 분석과 의사결정에 집중하고 싶은 사용자.
*   **개발자/엔지니어:** 코드 리뷰, 문서 생성, 테스트 케이스 작성 등 정형화된 개발 워크플로우를 자동화하여 생산성을 높이고 싶은 사용자.
*   **사내 IT 지원팀:** 사내 시스템 장애 대응, 사용자 계정 관리, FAQ 응대 등 표준화된 절차(SOP)에 따른 업무를 자동화하여 응대 시간을 단축하고 싶은 팀.

---

### **4. 제품 로드맵: 단계별 개발 계획 (Phased Development Roadmap)**

본 서비스는 기술적 복잡성과 시장 가치를 고려하여 다음과 같은 단계별 로드맵에 따라 개발을 진행한다. 각 단계는 독립적으로 가치를 제공하며, 다음 단계의 성공을 위한 기반이 된다.

#### **Phase 1: MVP - 신뢰할 수 있는 자동화 코어 엔진 구축 (Reliable Automation Core)**

*   **목표:** 가장 핵심적인 '절차 기반 자동화'의 가치를 사용자에게 전달하고, 기술적 안정성을 확보한다.
*   **핵심 기능 범위:**
    1.  **절차 기반 모드 (Procedural Mode) 안정화:**
        *   LangGraph 기반의 워크플로우 실행 엔진을 완벽하게 구현.
        *   **명시적 워크플로우 실행:** 사용자가 채팅창에서 `/` 또는 버튼을 통해 실행할 워크플로우를 **직접 선택**하는 방식을 채택.
    2.  **기본 워크플로우 관리:**
        *   관리자가 제공하는 **공식 템플릿** 목록을 사용자가 조회하고 선택할 수 있는 기능.
        *   템플릿의 일부 파라미터(예: 이메일 주소, 파일 경로)를 수정하여 실행하는 기능.
    3.  **단일 스코프 RAG 구현:**
        *   RAG 기능은 **'개인용 컬렉션'**을 대상으로 먼저 구현하여 검색 파이프라인의 안정성을 확보.
    4.  **필수 보안 및 사용자 기능:**
        *   **Secrets Manager 연동 API 키 관리:** 사용자의 API 키를 AWS Secrets Manager, HashiCorp Vault와 같은 검증된 외부 Secrets Manager를 통해 안전하게 관리하는 것을 원칙으로 함. (DB 저장 금지)
        *   사용자 회원가입, 로그인, 개인 API 키 등록 기능.
    5.  **실시간 피드백 및 상태 표시:**
        *   WebSockets 또는 SSE를 활용하여 에이전트의 현재 작업 단계를 UI에 실시간으로 표시.

*   **이 단계에서 제외되는 기능:** `자율 모드`, `지능형 라우터`, `다중 컬렉션 RAG`, `하이브리드 워크플로우 편집기`.

#### **Phase 2: 유연성 및 협업 기능 확장 (Flexibility & Collaboration)**

*   **목표:** 단일 자동화를 넘어, 예측 불가능한 문제 해결 능력을 부여하고 팀 단위의 협업을 지원한다.
*   **핵심 기능 범위:**
    1.  **자율 모드 (Autonomous Mode) 도입:**
        *   ReAct 기반의 자율 에이전트 기능을 도입.
    2.  **지능형 라우터 (v1) 도입:**
        *   사용자 쿼리를 분석하여 워크플로우를 '추천'하거나, 점수가 높은 경우 자동으로 실행하는 지능형 라우팅 기능 도입.
    3.  **다중 컬렉션 RAG 확장:**
        *   '공용', '팀' 컬렉션을 도입하고, 사용자 권한에 따라 여러 컬렉션을 동시에 검색하는 로직 구현.
    4.  **사용자 정의 워크플로우 (v1):**
        *   기존 템플릿을 복사하여 '사용자 정의 템플릿'으로 저장하는 기능.
    5.  **Human-in-the-Loop 기능 강화:**
        *   '자율 모드'에서 에이전트의 실행 계획을 사용자가 수정/확인하는 기능 도입.

#### **Phase 3: 생태계 및 지능 고도화 (Ecosystem & Intelligence)**

*   **목표:** 사용자가 직접 가치를 창출하고 공유하는 플랫폼으로 진화하며, 데이터 기반으로 서비스를 고도화한다.
*   **핵심 기능 범위:**
    1.  **하이브리드 워크플로우 편집기:**
        *   시각적(노코드) 편집과 대화형(자연어) 편집을 모두 지원하는 완전한 워크플로우 편집기 개발.
    2.  **워크플로우 마켓플레이스:**
        *   사용자가 자신의 템플릿을 커뮤니티에 공유하고, 다른 사용자의 템플릿을 가져와 사용할 수 있는 기능.
    3.  **피드백 기반 성능 개선:**
        *   수집된 사용자 피드백을 분석하여 워크플로우 템플릿을 개선하고, 인기 있는 작업을 새로운 템플릿으로 제안.
    4.  **운영 및 성능 대시보드:**
        *   제품팀을 위한 에이전트 성능 대시보드 구축 및 사용자를 위한 비용 관리 대시보드 고도화.
    5.  **엔터프라이즈 기능:**
        *   RBAC, 승인 워크플로우, 프리미엄 컨설팅 템플릿 제공.

### **5. MVP(Phase 1) 핵심 기능 요구사항 상세**

#### **5.1. Agent Core**
*   **실행 엔진:** LangGraph 기반의 '절차 기반 모드'를 안정적으로 실행.
*   **워크플로우 정의:** JSON 형식의 워크플로우 정의를 해석하고 실행.
*   **상태 추적:** `State` 객체를 통해 워크플로우의 각 단계, 데이터, 로그를 추적.
*   **실패 복구:** 작업 실패 시 사용자에게 알리고, [재시도] 또는 [중단] 선택지를 제공.

#### **5.2. 워크플로우 및 사용자 인터페이스**
*   **UI:** 텍스트 기반 채팅 UI 제공. 이미지, 문서, URL 첨부 가능.
*   **워크플로우 실행:** `/` 커맨드 또는 UI 버튼을 통해 사용자가 명시적으로 워크플로우 템플릿을 선택하여 실행.
*   **템플릿 관리:** 관리자가 사전에 정의한 '공식 템플릿' 목록을 제공.
*   **파라미터 수정:** 워크플로우 실행 시 필요한 변수(예: 이메일 주소, 검색 키워드)를 사용자가 입력/수정할 수 있는 인터페이스 제공.
*   **상태 시각화:** 에이전트의 현재 상태(`생각 중`, `[도구] 실행 중` 등)를 SSE 기반으로 실시간 표시.
*   **피드백 수집:** 작업 완료 후 "👍/👎" 평가 버튼을 통해 사용자 피드백 수집.

#### **5.3. RAG (Retrieval-Augmented Generation)**
*   **컬렉션:** '개인용 컬렉션'을 대상으로 RAG 기능 구현. (`private_user_id_docs`)
*   **데이터 수집:** 사용자가 업로드한 파일을 Celery 기반 비동기 파이프라인으로 처리 (청킹, 임베딩, 저장).
*   **검색 전략:** Hybrid Search (키워드+의미) + Re-ranker를 통해 검색 정확도 확보.
*   **임베딩/LLM:** 사용자가 개인 API 키를 입력하여 Voyage AI, OpenAI 등의 모델을 사용.

#### **5.4. 메모리 및 데이터 관리**
*   **에이전트 메모리:** 단기(세션), 장기(요약본), 작업(State) 메모리 분리 관리.
*   **데이터베이스:** PostgreSQL + pgvector (메타데이터, 장기 메모리), Qdrant (RAG 벡터 DB).

#### **5.5. 사용자 및 보안**
*   **인증:** 사용자 회원가입, 로그인 기능.
*   **API 키 관리:** **외부 Secrets Manager(AWS Secrets Manager, HashiCorp Vault 등) 연동을 통한 API 키 관리 시스템을 최우선으로 구축.**

### **6. 기술 스택 (Tech Stack)**

*   **Frontend:** React, TypeScript, Tailwind CSS
*   **Backend:** FastAPI (Python), Pydantic, LangChain, **LangGraph**
*   **비동기 작업 처리:** Celery
*   **데이터베이스:**
    *   **메타데이터/장기 메모리:** PostgreSQL + pgvector
    *   **RAG 벡터 DB:** Qdrant
*   **배포/인프라 (예상):** Docker, Kubernetes, Nginx

---

### **7. 비기능적 요구사항 (Non-Functional Requirements)**

*   **성능:** 사용자의 요청 후 Agent의 첫 응답은 3초 이내에 시작되어야 함 (실제 도구 실행 시간 제외).
*   **확장성:** 향후 사용자 및 워크플로우 증가에 따라 시스템이 수평적으로 확장 가능해야 함.
*   **보안:** 사용자의 API 키 및 모든 데이터는 전송 및 저장 시 암호화되어야 하며, 최고 수준의 보안 관행을 준수해야 함.
*   **모니터링:** Agent의 실행 과정, 각 단계의 성공/실패 여부, 사용된 토큰 수 등을 추적할 수 있는 로깅 및 모니터링 시스템(예: LangSmith)을 구축해야 함.

---

### **8. UX/UI 디자인 가이드 (UX/UI Design Guide)**

*   **핵심 철학: "투명한 조수석 (The Transparent Co-pilot)"**
    *   사용자가 AI의 작업 과정을 명확하게 인지하고 항상 최종 통제권을 갖도록 설계한다.
*   **온보딩:** 추천 템플릿과 상호작용형 튜토리얼을 통해 3분 내에 첫 성공 경험을 제공한다.
*   **인터페이스:**
    *   **동적 상태 표시:** 에이전트의 현재 상태(생각 중, 도구 실행 중 등)를 시각적으로 표시.
    *   **구조화된 응답:** 체크리스트, 테이블, 코드 블록, 참조 소스 각주 등 구조화된 형태로 정보를 제공.
    *   **명시적 트리거:** `/` 커맨드를 통해 사용자가 기능을 쉽게 발견하고 실행하도록 지원.
*   **디자인 키워드:** Transparent(투명성), Controllable(통제성), Structured(구조성), Conversational(대화성), Forgiving(관용성).
