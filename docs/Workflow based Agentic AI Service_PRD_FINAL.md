# **절차 기반 Agentic AI 서비스 PRD (Product Requirements Document)**

*   **문서 버전:** v3.0 (MVP & Phased Roadmap + MCP Integration)
*   **최종 수정일:** 2025년 7월 10일 (Phase 3 설계 반영)
*   **문서 목적:** '절차 기반 Agentic AI 서비스'의 제품 요구사항, 기술 명세, 개발 로드맵을 정의하여 팀 전체의 목표를 통일하고 성공적인 제품 개발을 위한 가이드를 제공함.

---

### **1. 제품 개요 (Overview)**

본 문서는 특정 업무 수행 절차(SOP)를 AI Agent의 작업 계획(Planning) 단계에 주입하여, 예측 가능하고 안정적인 결과물을 도출하는 **"절차 기반 Agentic AI 서비스"** 개발을 위한 제품 요구사항 명세서(PRD)입니다.

본 서비스의 핵심은 **'워크플로우 생태계'** 구축에 있습니다. 사용자는 공식 템플릿, 맞춤형 컨설팅 템플릿, 그리고 자신이 직접 만든 커스텀 템플릿을 활용하여 반복적인 업무를 자동화할 수 있습니다. 에이전트는 사용자의 요청에 따라 **'절차 기반 모드'** 또는 **'자율 모드'**로 동작하며, 정형화된 업무와 비정형화된 업무를 모두 처리할 수 있는 유연성을 제공합니다.

**v3.0 주요 개선사항**:
- **MCP(Model Context Protocol) 기반 도구 통합** 도입으로 확장 가능한 도구 생태계 구축
- **지능형 워크플로우 변환 시스템** 추가로 사용자 친화적인 워크플로우 생성 지원
- **실시간 상태 스트리밍** 및 **Human-in-the-Loop** 기능으로 투명성과 제어성 강화

---

### **2. 목표 (Goals)**

*   **신뢰성 및 유연성:** 사전 정의된 업무는 '절차 기반 모드'로 완벽하게 수행하고, 정의되지 않은 업무는 '자율 모드'로 유연하게 대처하여 신뢰성과 범용성을 동시에 확보합니다.
*   **협업 및 확장성:** 개인, 팀, 조직 단위의 데이터 접근 및 공유를 지원하여 협업 효율성을 높이고, 복잡한 비즈니스 워크플로우를 자동화할 수 있는 확장 가능한 플랫폼을 구축합니다.
*   **사용자 경험 혁신:** 복잡한 업무를 간단한 채팅으로 지시하고, Agent가 자율적으로 처리하는 과정을 투명하게 관찰할 수 있는 직관적인 사용자 경험을 제공합니다.
*   **표준화된 도구 생태계:** MCP 프로토콜을 통해 표준화된 도구 통합 환경을 제공하여, 새로운 도구 추가 및 기존 도구 확장이 용이한 플랫폼을 구축합니다.

---

### **3. 사용자 페르소나 (User Persona)**

*   **비즈니스 분석가/기획자:** 반복적인 데이터 분석, 시장 조사, 보고서 초안 작성 등의 업무를 자동화하여 핵심적인 분석과 의사결정에 집중하고 싶은 사용자.
*   **개발자/엔지니어:** 코드 리뷰, 문서 생성, 테스트 케이스 작성 등 정형화된 개발 워크플로우를 자동화하여 생산성을 높이고 싶은 사용자.
*   **사내 IT 지원팀:** 사내 시스템 장애 대응, 사용자 계정 관리, FAQ 응대 등 표준화된 절차(SOP)에 따른 업무를 자동화하여 응대 시간을 단축하고 싶은 팀.

**공통 특징**: 반복적이고 체계화 가능한 업무 프로세스를 보유하고 있으며, 각자의 도메인에 특화된 도구와 시스템을 사용하는 사용자들. 업무 특성에 따라 필요한 MCP 도구가 다르므로, 플랫폼은 다양한 도구 생태계를 지원해야 함.

### **4. 제품 로드맵: 단계별 개발 계획 (Phased Development Roadmap)**

본 서비스는 기술적 복잡성과 시장 가치를 고려하여 다음과 같은 단계별 로드맵에 따라 개발을 진행한다. 각 단계는 독립적으로 가치를 제공하며, 다음 단계의 성공을 위한 기반이 된다.

#### **Phase 1: MVP - 신뢰할 수 있는 자동화 코어 엔진 구축 (Reliable Automation Core)**

*   **목표:** 가장 핵심적인 '절차 기반 자동화'의 가치를 사용자에게 전달하고, 기술적 안정성을 확보한다.
*   **핵심 기능 범위:**
    1.  **절차 기반 모드 (Procedural Mode) 안정화:**
        *   LangGraph 기반의 워크플로우 실행 엔진을 완벽하게 구현.
        *   **명시적 워크플로우 실행:** 사용자가 채팅창에서 `/` 또는 버튼을 통해 실행할 워크플로우를 **직접 선택**하는 방식을 채택.
    2.  **기본 워크플로우 관리:**
        *   관리자가 제공하는 **공식 템플릿** 목록을 사용자가 조회하고 선택할 수 있는 기능.
        *   템플릿의 일부 파라미터(예: 이메일 주소, 파일 경로)를 수정하여 실행하는 기능.
    3.  **단일 스코프 RAG 구현:**
        *   RAG 기능은 **'개인용 컬렉션'**을 대상으로 먼저 구현하여 검색 파이프라인의 안정성을 확보.
    4.  **필수 보안 및 사용자 기능:**
        *   **Secrets Manager 연동 API 키 관리:** 사용자의 API 키를 AWS Secrets Manager, HashiCorp Vault와 같은 검증된 외부 Secrets Manager를 통해 안전하게 관리하는 것을 원칙으로 함. (DB 저장 금지)
        *   사용자 회원가입, 로그인, 개인 API 키 등록 기능.
    5.  **실시간 피드백 및 상태 표시:**
        *   Server-Sent Events(SSE)를 활용하여 에이전트의 현재 작업 단계를 UI에 실시간으로 표시.

*   **이 단계에서 제외되는 기능:** `자율 모드`, `지능형 라우터`, `다중 컬렉션 RAG`, `워크플로우 변환 시스템`.

#### **Phase 2: 유연성 및 협업 기능 확장 (Flexibility & Collaboration)**

*   **목표:** 단일 자동화를 넘어, 예측 불가능한 문제 해결 능력을 부여하고 팀 단위의 협업을 지원한다.
*   **핵심 기능 범위:**
    1.  **자율 모드 (Autonomous Mode) 도입:**
        *   ReAct 기반의 자율 에이전트 기능을 도입.
    2.  **지능형 라우터 (v1) 도입:**
        *   사용자 쿼리를 분석하여 워크플로우를 '추천'하거나, 점수가 높은 경우 자동으로 실행하는 지능형 라우팅 기능 도입.
    3.  **다중 컬렉션 RAG 확장:**
        *   '공용', '팀' 컬렉션을 도입하고, 사용자 권한에 따라 여러 컬렉션을 동시에 검색하는 로직 구현.
    4.  **사용자 정의 워크플로우 (v1):**
        *   기존 템플릿을 복사하여 '사용자 정의 템플릿'으로 저장하는 기능.
    5.  **Human-in-the-Loop 기능 강화:**
        *   '자율 모드'에서 에이전트의 실행 계획을 사용자가 수정/확인하는 기능 도입.
        *   WebSocket 기반 실시간 사용자 상호작용 지원.

#### **Phase 3: 생태계 및 지능 고도화 (Ecosystem & Intelligence)**

*   **목표:** 사용자가 직접 가치를 창출하고 공유하는 플랫폼으로 진화하며, 데이터 기반으로 서비스를 고도화한다.
*   **핵심 기능 범위:**
    1.  **지능형 워크플로우 변환 시스템:**
        *   사용자의 간단한 업무 설명을 완전한 JSON 워크플로우로 자동 변환.
        *   LLM 기반 비즈니스 로직 분석 및 조건부 분기 자동 생성.
        *   대화형 수정 인터페이스 제공.
    2.  **워크플로우 마켓플레이스:**
        *   사용자가 자신의 템플릿을 커뮤니티에 공유하고, 다른 사용자의 템플릿을 가져와 사용할 수 있는 기능.
    3.  **피드백 기반 성능 개선:**
        *   수집된 사용자 피드백을 분석하여 워크플로우 템플릿을 개선하고, 인기 있는 작업을 새로운 템플릿으로 제안.
    4.  **운영 및 성능 대시보드:**
        *   제품팀을 위한 에이전트 성능 대시보드 구축 및 사용자를 위한 비용 관리 대시보드 고도화.
    5.  **엔터프라이즈 기능:**
        *   RBAC, 승인 워크플로우, 프리미엄 컨설팅 템플릿 제공.

### **5. MVP(Phase 1) 핵심 기능 요구사항 상세**

#### **5.1. Agent Core**
*   **실행 엔진:** LangGraph 기반의 '절차 기반 모드'를 안정적으로 실행.
*   **아키텍처:** 플랫 노드 구조를 채택하여 단일 책임 원칙 준수 및 재사용성 극대화.
*   **워크플로우 정의:** JSON 형식의 워크플로우 정의를 해석하고 실행.
*   **상태 추적:** `AgentState` 객체를 통해 워크플로우의 각 단계, 데이터, 로그를 추적.
*   **실패 복구:** 작업 실패 시 사용자에게 알리고, [재시도] 또는 [중단] 선택지를 제공.
*   **노드 타입:** 제어 흐름, 작업 실행, 상태 관리, 도구 통합 노드로 분류하여 체계적 관리.

#### **5.2. 하이브리드 도구 통합 시스템**
*   **내부 최적화 기능:** 자주 사용되고 성능이 중요한 핵심 AI 기능들을 내부 서비스로 직접 처리
    - RAG 검색: 직접 Qdrant 접근으로 50-150ms 응답 시간 달성
    - LLM 생성: 캐싱된 클라이언트로 최적화된 토큰 관리
    - 메모리 관리: 인메모리 상태 관리로 즉시 접근
*   **MCP 기반 외부 도구:** 비즈니스 특화 도구 및 외부 시스템을 MCP 프로토콜로 표준화 통합
    - API 호출, 데이터베이스 연동, 파일 처리 등 도메인별 도구
    - 사용자 요구사항에 따른 커스텀 도구 확장 지원
*   **통합 노드 실행 엔진:** 워크플로우 실행 시 노드 타입에 따라 최적의 실행 경로 자동 선택
    - 내부 노드: 직접 메서드 호출로 최고 성능
    - 외부 노드: MCP 프로토콜을 통한 표준화된 도구 실행
*   **투명한 통합:** 사용자는 내부/외부 구분 없이 동일한 JSON 워크플로우 문법으로 사용

#### **5.3. 워크플로우 및 사용자 인터페이스**
*   **UI:** 텍스트 기반 채팅 UI 제공. 이미지, 문서, URL 첨부 가능.
*   **워크플로우 실행:** `/` 커맨드 또는 UI 버튼을 통해 사용자가 명시적으로 워크플로우 템플릿을 선택하여 실행.
*   **템플릿 관리:** 관리자가 사전에 정의한 '공식 템플릿' 목록을 제공.
*   **파라미터 수정:** 워크플로우 실행 시 필요한 변수(예: 이메일 주소, 검색 키워드)를 사용자가 입력/수정할 수 있는 인터페이스 제공.
*   **실시간 상태 시각화:** SSE 기반으로 에이전트의 현재 상태(`생각 중`, `[도구] 실행 중` 등)를 실시간 표시.
*   **피드백 수집:** 작업 완료 후 "👍/👎" 평가 버튼을 통해 사용자 피드백 수집.

#### **5.4. 비동기 실행 및 상태 관리**
*   **비동기 API:** `POST /workflows/{id}/execute` → 202 Accepted + execution_id 반환.
*   **실시간 스트리밍:** SSE를 통한 워크플로우 실행 과정 실시간 전달.
*   **상태 지속성:** Redis/DB를 통한 실행 상태 영구 저장으로 연결 끊김 시에도 복구 가능.
*   **에러 처리:** 단계별 실패 시나리오 대응 및 사용자 선택 기반 복구 메커니즘.

#### **5.5. RAG (Retrieval-Augmented Generation)**
*   **컬렉션:** '개인용 컬렉션'을 대상으로 RAG 기능 구현. (`private_user_id_docs`)
*   **데이터 수집:** 사용자가 업로드한 파일을 Celery 기반 비동기 파이프라인으로 처리 (청킹, 임베딩, 저장).
*   **검색 전략:** Hybrid Search (키워드+의미) + Re-ranker를 통해 검색 정확도 확보.
*   **임베딩/LLM:** 사용자가 개인 API 키를 입력하여 Voyage AI, OpenAI 등의 모델을 사용.

#### **5.6. 메모리 및 데이터 관리**
*   **에이전트 메모리:** 단기(세션), 장기(요약본), 작업(State) 메모리 분리 관리.
*   **데이터베이스:** PostgreSQL + pgvector (메타데이터, 장기 메모리), Qdrant (RAG 벡터 DB).

#### **5.7. 사용자 및 보안**
*   **인증:** 사용자 회원가입, 로그인 기능.
*   **API 키 관리:** **외부 Secrets Manager(AWS Secrets Manager, HashiCorp Vault 등) 연동을 통한 API 키 관리 시스템을 최우선으로 구축.**

### **6. 기술 스택 (Tech Stack)**

### **6. 기술 스택 (Tech Stack)**

#### **6.1 Frontend**
*   **React, TypeScript, Tailwind CSS**
*   **상태 관리:** Zustand
*   **HTTP 클라이언트:** Axios (인터셉터, 에러 처리)
*   **실시간 통신:** EventSource (SSE), WebSocket

#### **6.2 Backend**
*   **FastAPI (Python), Pydantic, LangChain, LangGraph**
*   **하이브리드 실행 엔진:** 내부 최적화 서비스와 MCP 통합의 이중 아키텍처
*   **내부 핵심 서비스:** 
    - RAG Service (직접 Qdrant 연동)
    - LLM Service (캐싱된 OpenAI/Anthropic 클라이언트)
    - Memory Service (Redis 기반 상태 관리)
*   **MCP 통합:** Python MCP SDK를 통한 외부 도구 서버 관리
*   **비동기 작업 처리:** Celery + Redis
*   **API 문서:** OpenAPI/Swagger 자동 생성

#### **6.3 데이터베이스**
*   **메타데이터/장기 메모리:** PostgreSQL + pgvector
*   **RAG 벡터 DB:** Qdrant
*   **캐시/세션:** Redis
*   **상태 저장:** Redis (실행 상태), PostgreSQL (영구 저장)

#### **6.4 도구 통합**
*   **하이브리드 아키텍처:** 성능과 확장성을 모두 확보하는 이중 통합 전략
*   **내부 최적화 영역:**
    - 핵심 AI 기능 (RAG, LLM, 메모리)을 직접 처리
    - 네트워크 오버헤드 없는 최고 성능
    - 사용자 개인 데이터의 안전한 처리
*   **MCP 프로토콜 영역:** 
    - 비즈니스 도구 및 외부 시스템 통합
    - 표준화된 도구 통합 인터페이스
    - 사용자/조직별 커스텀 도구 확장
*   **동적 도구 발견:** 런타임에 사용 가능한 MCP 도구 자동 검색 및 스키마 수집
*   **플러그인 생태계:** 
    - 사용자가 필요에 따라 MCP 서버 추가/제거 가능
    - 서드파티 개발자가 도구 서버 개발 및 배포 가능
    - 도구별 독립적인 업데이트 및 버전 관리
*   **도구 메타데이터 관리:** 도구 설명, 입출력 스키마, 비용 정보, 성능 특성 자동 수집

#### **6.5 배포/인프라**
*   **컨테이너화:** Docker (서비스별 독립 컨테이너)
*   **오케스트레이션:** Kubernetes (프로덕션), Docker Compose (개발)
*   **로드 밸런서:** Nginx
*   **보안:** HashiCorp Vault (Secrets 관리), JWT (인증)

### **7. 비기능적 요구사항 (Non-Functional Requirements)**

#### **7.1 성능**
*   **응답 시간:**
    - 워크플로우 실행 시작: < 200ms
    - 상태 조회: < 100ms
    - SSE 이벤트 전달: < 50ms
    - **내부 RAG 검색: < 150ms** (직접 벡터DB 접근)
    - **MCP 도구 호출: < 2초** (외부 시스템 연동)
    - 사용자의 요청 후 Agent의 첫 응답: < 3초 (실제 도구 실행 시간 제외)
*   **처리량:**
    - 동시 워크플로우 실행: 50개 이상
    - 사용자별 동시 실행 제한: 3개
    - API 요청 처리: 500 RPS
    - **내부 서비스: 1000+ RPS, MCP 도구: 100 RPS**

#### **7.2 확장성**
*   **수평적 확장:** 향후 사용자 및 워크플로우 증가에 따라 시스템이 수평적으로 확장 가능해야 함.
*   **MCP 서버 확장:** 새로운 도구 추가 시 기존 시스템 수정 없이 MCP 서버만 추가.
*   **워크플로우 템플릿:** JSON 기반으로 새로운 워크플로우 타입 동적 추가 지원.

#### **7.3 보안**
*   **데이터 암호화:** 사용자의 API 키 및 모든 데이터는 전송 및 저장 시 암호화되어야 하며, 최고 수준의 보안 관행을 준수해야 함.
*   **MCP 보안:** 각 MCP 서버는 샌드박스 환경에서 실행, 최소 권한 원칙 적용.
*   **인증/인가:** JWT 기반 인증, RBAC 기반 권한 관리.
*   **API 보안:** 레이트 리미팅, CORS 설정, 입력 검증.

#### **7.4 모니터링**
*   **실행 추적:** Agent의 실행 과정, 각 단계의 성공/실패 여부, 사용된 토큰 수 등을 추적할 수 있는 로깅 및 모니터링 시스템(예: LangSmith)을 구축해야 함.
*   **MCP 모니터링:** 도구별 호출 횟수, 성공률, 응답 시간, 에러율 추적.
*   **비용 추적:** 사용자별 LLM 토큰 사용량 및 비용 실시간 모니터링.
*   **성능 메트릭:** 워크플로우별 평균 실행 시간, 사용자 만족도, 시스템 리소스 사용률.

#### **7.5 가용성**
*   **서비스 가용성:** 99.9% 이상 (월 43분 이하 다운타임)
*   **장애 복구:** 자동 재시작, 헬스 체크, 서킷 브레이커 패턴 적용.
*   **데이터 백업:** 일일 자동 백업, Point-in-time Recovery 지원.

### **8. UX/UI 디자인 가이드 (UX/UI Design Guide)**

#### **8.1 핵심 디자인 철학**
**"투명한 조수석 (The Transparent Co-pilot)"**
*   사용자가 AI의 작업 과정을 명확하게 인지하고 항상 최종 통제권을 갖도록 설계한다.
*   실시간 상태 표시를 통해 "AI가 지금 무엇을 하고 있는지" 항상 투명하게 보여준다.

#### **8.2 사용자 온보딩**
*   **3분 성공 경험:** 추천 템플릿과 상호작용형 튜토리얼을 통해 3분 내에 첫 성공 경험을 제공한다.
*   **점진적 학습:** 기본 기능부터 고급 기능까지 단계적으로 학습할 수 있는 가이드 제공.

#### **8.3 인터페이스 설계 원칙**
*   **동적 상태 표시:** 
    - 에이전트의 현재 상태(생각 중, 도구 실행 중 등)를 시각적으로 표시.
    - 진행률 바와 예상 완료 시간 제공.
    - 각 단계별 실행 결과 및 소요 시간 표시.
*   **구조화된 응답:** 
    - 체크리스트, 테이블, 코드 블록, 참조 소스 각주 등 구조화된 형태로 정보를 제공.
    - 워크플로우 결과를 섹션별로 나누어 가독성 향상.
*   **명시적 트리거:** 
    - `/` 커맨드를 통해 사용자가 기능을 쉽게 발견하고 실행하도록 지원.
    - 컨텍스트 메뉴와 단축키 제공.
*   **Human-in-the-Loop UI:**
    - 사용자 입력이 필요한 시점에서 명확한 안내와 선택지 제공.
    - 타임아웃 표시 및 기본값 옵션 제공.

#### **8.4 반응형 및 접근성**
*   **다중 디바이스 지원:** 데스크톱, 태블릿, 모바일에서 일관된 경험 제공.
*   **접근성:** WCAG 2.1 AA 기준 준수, 키보드 네비게이션, 스크린 리더 지원.
*   **다국어:** 한국어 우선, 향후 영어 지원 확장 계획.

#### **8.5 디자인 키워드**
**Transparent(투명성), Controllable(통제성), Structured(구조성), Conversational(대화성), Forgiving(관용성), Real-time(실시간성)**
